# אפיון פרויקט: מערכת לסנכרון לוח זמנים בסמינר

## א. תיאור הפרויקט

**שם:** סנכרון לוח זמנים לסמינר (מסלול הנדסת תוכנה)

**מטרה:** לוח זמנים שמשתנה כל הזמן מגיע בזמן אמת לכל מי שרלוונטי אליו. המזכירה מנהלת את הלוח, ובכל שינוי נשלחת התראה אוטומטית לתלמידות ולמורה הרלוונטיות. כך מורות לא מבטלות שיעורים בגלל חוסר ידיעה.

**כיתות:** שני מחזורים.
- מחזור ה׳: ה1, ה2, ה3, ה4.
- מחזור ו׳: ו1, ו2, ו3.

**משתמשים:**
- **מזכירה (ADMIN):** רואה ומשנה את כל לוחות הזמנים, שולחת הודעות, מנהלת משתמשים.
- **מורה (TEACHER):** רואה את השיעורים שלה, מוסיפה הערות פרטיות ושיעורי בית, צופה בהגשות, נותנת משוב, מתקשרת עם המזכירה.
- **תלמידה (STUDENT):** רואה מערכת שבועית ויומית של הכיתה שלה, מגישה שיעורי בית, מנהלת מחברת אישית.

**החלטות תכנון (שלי):**
- אין הרשמה עצמית. המזכירה יוצרת את החשבונות. זה מתאים לסמינר סגור ובטוח יותר.
- מערכת השעות היא שבועית וקבועה. כל שיעור הוא משבצת שחוזרת כל שבוע (יום, שעות, חדר). המזכירה משנה אותה, ובכל שינוי נשלחת התראה לתלמידות ולמורה הרלוונטיות.
- **שיעור מבוטל** לא מוצג בכלל במערכת של התלמידות והמורה, לא ביום המקורי ולא בשום יום אחר. רק המזכירה רואה אותו בלוח הניהול, עם סימון "מבוטל". היא יכולה להחזיר אותו.
- **שיעור שהועבר** מופיע רק ביום ובשעה החדשים, ולא ביום המקורי. ההעברה היא עריכה של היום, השעה או החדר, וההתראה מציינת מה היה ומה הפך.
- **ה־token נשמר בשרת בלבד.** אחרי התחברות הדפדפן מקבל רק מפתח אקראי קצר (`sessionKey`). ה־JWT עצמו נשמר בטבלה בשרת (עם תוקף), והשרת מוצא אותו לפי המפתח בכל בקשה. התנתקות מבטלת את המפתח מיד בצד השרת.
- ההתראות נשמרות במסד הנתונים ומוצגות באפליקציה. אין שליחת מייל או SMS, כי הם דורשים שירותים בתשלום. ה־React יבדוק התראות חדשות מדי כמה שניות.
- במקום "תיקייה" התלמידה מעלה כמה קבצים להגשה (עד 5 קבצים, עד 5MB כל אחד). הקבצים נשמרים ב־PostgreSQL, כי בשירותי ענן חינמיים הדיסק נמחק בכל הפעלה מחדש.

## ד. תכנון מסד הנתונים (PostgreSQL + Prisma)

כל ה־id הם מסוג UUID (Primary Key). כל הטבלאות כוללות `createdAt`.

### 1. `users` – משתמשים
| שדה | טיפוס | חובה | הערות |
|---|---|:-:|---|
| id | UUID | ✅ | PK |
| fullName | טקסט | ✅ | |
| email | טקסט | ✅ | ייחודי |
| passwordHash | טקסט | ✅ | bcrypt, לא מוחזר ב־API |
| role | enum: ADMIN, TEACHER, STUDENT | ✅ | |
| classId | UUID | רק לתלמידה | FK → classes |
| isActive | בוליאני | ✅ | ברירת מחדל true |

אילוץ: תלמידה חייבת classId, מורה ומזכירה לא.

### 2. `classes` – כיתות
id (PK), `name` (ייחודי, ה1...), `grade` (enum: HEH, VAV, כלומר מחזור ה׳ או ו׳).
קשר: כיתה אחת ← הרבה תלמידות והרבה שיעורים.

### 3. `subjects` – מקצועות
id (PK), `name` (ייחודי).

### 4. `lessons` – שיעורים (משבצת שבועית)
| שדה | טיפוס | חובה | הערות |
|---|---|:-:|---|
| id | UUID | ✅ | PK |
| subjectId | UUID | ✅ | FK → subjects |
| teacherId | UUID | ✅ | FK → users (תפקיד TEACHER) |
| classId | UUID | ✅ | FK → classes |
| dayOfWeek | מספר 0-5 | ✅ | 0 = ראשון, 5 = שישי |
| startTime / endTime | טקסט HH:mm | ✅ | סיום אחרי התחלה |
| room | טקסט | ✅ | מספר חדר |
| status | enum: ACTIVE, CANCELLED | ✅ | ברירת מחדל ACTIVE. שיעור מבוטל מוסתר מתלמידות ומורות |
| changeNote | טקסט | ❌ | הסבר לשינוי אחרון (למשל "הועבר מיום ב׳") |

אילוצים: מניעת התנגשות. לא יכולות להיות שתי שיעורים חופפים לאותה מורה, לאותה כיתה או לאותו חדר באותו יום ושעה (השרת בודק ומחזיר 409).

### 5. `notes` – הערות אישיות על שיעור (מורה או תלמידה)
id, authorId (FK → users), lessonId (FK, התווית), content (חובה), updatedAt.
ההערה אישית: רק מי שכתבה אותה רואה אותה. מורה כותבת רק על שיעורים שלה, ותלמידה רק על שיעורים של כיתתה. המחברת של התלמידה היא רשימת ההערות שלה, והיא לא קשורה להגשות.

### 6. `homeworks` – שיעורי בית
id, lessonId (FK), createdById (FK מורה), title (חובה), description (חובה), lessonDate (תאריך השיעור, חייב להיות היום), dueDate (חובה, אחרי lessonDate).

### 7. `submissions` – הגשות
id, homeworkId (FK), studentId (FK), comment (אופציונלי), submittedAt, updatedAt.
אילוץ: ייחודי (homeworkId, studentId). הגשה חוזרת מעדכנת.

### 8. `submission_files` – קבצי הגשה
id, submissionId (FK, מחיקה בשרשרת), fileName, mimeType, sizeBytes, data (בינארי).
אילוצים: עד 5 קבצים להגשה, עד 5MB כל אחד, סוגים מותרים: pdf, zip, txt, תמונות, doc/docx, ופורמטי קוד נפוצים.

### 9. `feedbacks` – משוב מורה על הגשה
id, submissionId (FK, ייחודי), teacherId (FK), content (חובה), updatedAt.

### 10. `sessions` – מפתחות התחברות (ה־token נשמר כאן)
id, userId (FK), keyHash (hash של המפתח האקראי, ייחודי; המפתח עצמו לא נשמר), jwt (ה־token), expiresAt, revokedAt (אופציונלי).
הדפדפן מקבל רק את המפתח. בכל בקשה השרת מוצא את הרשומה, בודק שלא פג תוקף ולא בוטל, ומאמת את ה־JWT.

### 11. `notifications` – התראות
id, userId (FK), type (enum: LESSON_CHANGED, ANNOUNCEMENT, HOMEWORK_ADDED, FEEDBACK_ADDED, MESSAGE), title, body, lessonId (אופציונלי), isRead (ברירת מחדל false).

### 12. `announcements` – הודעות מהמזכירה
id, senderId (FK), audience (enum: ALL_STUDENTS, ALL_TEACHERS, GRADE, CLASS), grade (אופציונלי), classId (אופציונלי), title, body.
בשליחה נוצרת התראה לכל נמען.

### 13. `teacher_messages` – שיחה מורה–מזכירה
id, teacherId (FK, הבעלים של השיחה), senderId (FK), body (חובה), readAt (אופציונלי).

### קשרים
- כיתה 1:N תלמידות; כיתה 1:N שיעורים.
- מורה 1:N שיעורים; מקצוע 1:N שיעורים.
- שיעור 1:N שיעורי בית; שיעורי בית 1:N הגשות; הגשה 1:N קבצים; הגשה 1:1 משוב.
- משתמש (מורה או תלמידה) 1:N הערות אישיות; שיעור 1:N הערות; משתמש 1:N התראות; משתמש 1:N מפתחות התחברות.

## ה. Endpoints

כל הכתובות מתחילות ב־`/api`. כל Endpoint פרטי דורש `Authorization: Bearer <sessionKey>`. המפתח הוא ערך אקראי שהשרת נותן בהתחברות, וה־JWT עצמו נשאר בשרת. בלי מפתח תקין מחזירים 401, ובלי הרשאה 403.

### אימות
| Method | URL | הרשאה | תיאור |
|---|---|---|---|
| GET | /api/health | ציבורי | בדיקת תקינות |
| POST | /api/auth/login | ציבורי | Request: `{email, password}`. Response: `{sessionKey, expiresAt, user}` |
| POST | /api/auth/logout | מחוברת | ביטול המפתח בשרת |
| GET | /api/auth/me | מחוברת | המשתמשת לפי המפתח |
| POST | /api/auth/change-password | מחוברת | `{currentPassword, newPassword}` |

### משתמשים, כיתות ומקצועות (מזכירה)
| Method | URL | תיאור |
|---|---|---|
| GET/POST | /api/users | רשימה (סינון `role`, `classId`, `search`) / יצירה |
| GET/PATCH | /api/users/:id | פרטים / עדכון (כולל השבתה ואיפוס סיסמה) |
| GET | /api/classes | רשימת כיתות (כל משתמשת מחוברת) |
| POST/PATCH | /api/classes, /api/classes/:id | יצירה / עדכון (מזכירה) |
| GET | /api/subjects | רשימת מקצועות (כל משתמשת מחוברת) |
| POST/PATCH | /api/subjects, /api/subjects/:id | יצירה / עדכון (מזכירה) |

### לוח זמנים
